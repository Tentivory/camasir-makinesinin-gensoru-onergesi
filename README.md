# T.C. Çamaşır Makinesi Genel Kurulu
## Gensoru Önergesi Üretim ve Oylama Protokolü

Bu depo bir şaka değildir.  
Bu depo bir şakayı çok ciddiye alma sanatıdır.  
Bu depo çamaşır makinesinin yasama organına dönüştüğü o tarihi anı belgeler.

> Sıkma turu güven oylamasıdır.  
> Köpük seviyesi bütçe açığıdır.  
> Eksik çorap, muhalefettir.

## Neden var?

Çünkü bir vatandaş (siz) bir gün makinenin kapağını açtı ve içinden tutanak çıktı.  
Tutanak şunu söylüyordu: *"Bu evde yeterince soru sorulmuyor."*

Biz de sorduk. Makine cevap verdi. Cevap ıslaktı.

## Kurulum

```bash
git clone https://github.com/Tentivory/camasir-makinesinin-gensoru-onergesi.git
cd camasir-makinesinin-gensoru-onergesi
python3 gensoru.py
```

Daha uzun oturum için (en fazla 9 madde, Anayasa böyle istiyor iddia ediyoruz):

```bash
python3 gensoru.py 5
```

## Ne yapar?

- Rastgele ama resmi görünen gensoru maddeleri üretir.
- Kabul / ret / çekimser / kayıp-çorap oylarını sayar.
- Muhalefet kürsüsüne köpük sıçratır.
- En sonda damga, imza, tarih ve isim basar.
- Bir satır "kalibrasyon" basar. O satıra bakmayın. Bakarsanız bakmış olursunuz.
